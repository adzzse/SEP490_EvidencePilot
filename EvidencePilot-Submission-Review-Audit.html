1. Executive Verdict / Kết luận điều hành

PARTIAL The submission→review spine exists and is coherent, but the Instructor cannot answer "Is this submitted section academically acceptable, and what exactly should change?" from one place. Snapshot + rounds + anchored feedback + trace lifecycle are CONFIRMED in backend; fragmented in UI.

Critical gaps: snapshot freezes sections only; no acknowledgement entity (handoff is the substitute); standards invisible + never gate submit/approve; no section-level review state; replies table unwired; extra instructor AI check would contaminate student history.

MỘT PHẦN Khung nộp→duyệt tồn tại và mạch lạc, nhưng giảng viên chưa thể trả lời "Mục nộp có đạt chuẩn học thuật không, cần sửa gì?" tại một nơi. Snapshot + vòng duyệt + nhận xét gắn neo + vòng đời trace đã CONFIRMED ở backend nhưng phân mảnh ở UI.

Khoảng trống chính: snapshot chỉ lưu mục viết; không có thực thể xác nhận (acknowledgement); chuẩn vô hình + không chặn nộp/duyệt; không có trạng thái duyệt từng mục; bảng replies chưa dùng; giảng viên chạy AI thêm sẽ làm bẩn lịch sử của sinh viên.

3. Current Review Aggregate / Đối tượng duyệt

No single clean aggregate. Working aggregate = FeedbackRequest (latest) + Project. Request = "this submission under review" (one row/round, latest-wins). Project.status = operational lock. Checkpoint = word-count support snapshot. ReviewSnapshot = AI critique cache (unrelated). Job = transport; Round = AI history; Trace = finding state.

Không có một aggregate duy nhất. Thực tế = FeedbackRequest (mới nhất) + Project. Request là "bài nộp đang duyệt" (mỗi vòng một dòng). Project.status là khóa vận hành. Checkpoint chỉ đếm từ. ReviewSnapshot là cache AI, không liên quan.

5. Citation / Evidence Review Audit / Trích dẫn & bằng chứng

5.1 Lifecycle — CONFIRMED

POST .../review/source-matches → job → ai.evaluation.queue → Qdrant topK 20→3 + generate → Round + Traces → student decide → edit stamps STALE → recheck → instructor review.

5.2–5.3 State model

Round: id/project/section/version/requestedBy/fingerprints/generation_meta. Trace: before (finding_index, excerpt+offsets, rationale, confidence, source/quote/relation); after (7 student_actions, after_passage ≤1200ch, fingerprint/version); verdicts (outcome RESOLVED|PARTIALLY_RESOLVED|UNRESOLVED|STALE; judgment EFFECTIVE|PARTIAL|INEFFECTIVE + recheck). No before_passage column (before = excerpt + fingerprints).

finding → NULL(unaddressed) → decide: DISMISS_WITH_REASON→UNRESOLVED | edit→UNRESOLVED/STALE
→ instructor EFFECTIVE→RESOLVED | PARTIAL→PARTIALLY_RESOLVED | INEFFECTIVE→UNRESOLVED
ignored ≈ NULL/STALE (no code concept) | resolved ONLY via instructor

"18 findings, 3 used": all 18 persist; 3 have action+after_passage; 15 remain NULL/UNRESOLVED/STALE — distinguishable.

5.4–5.6 Visibility / judgment / extra check

Full trace history on backend + EvidenceTraceReview.jsx page, but absent from the section review panel PARTIAL. Judgment locks traces CONFIRMED. Instructor rerun: UI absent, API 409 while submitted, would merge into student traces — NOT SUPPORTED cleanly.

Evidence: PaperController:469-515; AiEvaluationServiceImpl:81-109; EvidenceTraceService:64-441; EvidenceTraceReview.jsx.

5.1 Vòng đời — CONFIRMED

Sinh viên xin review → job async → tìm Qdrant + AI → Round + Traces → sinh viên quyết định → sửa → AI chấm lại → giảng viên chốt.

5.2–5.3 Trạng thái

Trace lưu: phát hiện (excerpt, rationale, nguồn), hành động SV (7 loại), đoạn sau sửa, outcome, verdict chấm lại, judgment của giảng viên. Bỏ qua ≈ NULL/STALE; dismissed = DISMISS_WITH_REASON; resolved chỉ do giảng viên EFFECTIVE.

5.4–5.6 Hiển thị

Lịch sử đầy đủ ở backend + trang EvidenceTraceReview riêng, nhưng vắng mặt trong panel duyệt theo mục. Giảng viên chạy AI thêm sẽ trộn vào lịch sử SV — KHÔNG hỗ trợ sạch.
